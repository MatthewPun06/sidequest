# README

This application is a way for people to find a time to hang out whether it be 
friend groups, families, or even two strangers. Simply sign up, integrate your 
calendars, add your friends, and find a time that works for all of you!

## Requirements

1) Python3
2) NodeJS
3) Docker Desktop
4) Bash

## Installation

1) Run `git clone https://github.com/MatthewPun06/sidequest.git`
2) Navigate to the repository `cd /path/to/sidequest`
3) Deploy!
